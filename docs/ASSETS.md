# Bundled visual assets

All storefront photography and fonts are served from `public/`; no runtime image or font API is called.

Photography source: Unsplash image CDN, downloaded as optimized JPEG fixtures. These are illustrative merchandising images, not photographs of actual seeded merchants. Verify final merchandising rights and replace fixtures with merchant-supplied assets before a commercial launch.

Source pattern: `https://images.unsplash.com/{image-ID}`. Main images use width 1000 / quality 85; grocery products use width 600 / quality 80.

DM Sans: Google Fonts, SIL Open Font License. The license is bundled in `public/fonts/OFL.txt`. Regular and semibold fonts are self-hosted. Editorial italic uses the system Georgia serif.

The Three.js bowl, ingredients, rice instances, lighting and animations are original procedural scene code. No external GLB models, textures or model licenses are required.
